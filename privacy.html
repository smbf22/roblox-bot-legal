Privacy Policy

Last updated: October 22, 2026

This application processes public Roblox profile information only when a visitor voluntarily confirms sharing it.

The information may include Roblox username, display name, user ID, profile URL, and the time consent was recorded.

Do not submit passwords, authentication cookies, or other secrets. This application does not need them.

Profile information is sent to the Discord channel configured by the bot owner. Access to that channel is controlled by Discord server permissions.

Generated links expire after 30 minutes. Temporary link data is stored in memory and may be lost when the application restarts.

Contact the application owner through the Discord server where the bot is installed for privacy questions or deletion requests.
